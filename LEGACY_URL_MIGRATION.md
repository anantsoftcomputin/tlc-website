# Legacy URL migration

| Legacy URL | New URL | Action |
|---|---|---|
| `/index.php` | `/` | Add at host if observed in analytics |
| `/about_us.php` | `/about` | 308 permanent redirect |
| `/services.php` | `/services` | 308 permanent redirect |
| `/package.php` | `/trips` | 308 permanent redirect |
| `/gallery.php` | `/destinations` | 308 permanent redirect |
| `/contactus.php` | `/contact` | 308 permanent redirect |

Additional parameterised legacy package URLs should be exported from Search Console/server logs before launch and mapped individually.
